# Пакет расчётов статьи об архитектуре обеспечения целостности

Статья: Кузьмин А.Р. «Архитектура обеспечения целостности цепочки сборки и обновления программного
обеспечения при реализации требований ГОСТ Р 56939-2024» (рукопись, 2026).

Все числа текста статьи и таблица 3 получены подсчётом по модели стандарта, сопоставлению и данным
прогона стенда. Назначенных или подобранных величин в расчёте нет.

## Что считается

- **Структура стандарта.** Число процессов, требований, артефактов и ссылок, граф процессов
  (формула (1) статьи), опора стадии выпуска (2), процессы, из которых есть путь к стадии выпуска 5.20.
- **Связь со свидетельствами стенда.** Сопоставление μ из [`crosswalk/scii-gate.yaml`](../../crosswalk/scii-gate.yaml),
  перенос состояний свидетельств на артефакты по правилу (5), артефакты, которые подтверждает эталонная
  запись B1.
- **Решения проверок на 16 сценариях стенда.** Проверки по артефактам стандарта (6) и решения модуля
  допуска по правилу (4) из прогона. Итоги по опасным и штатным сценариям.
- **Контур реагирования.** Пары сценариев O1→B1, B3→B1, B5a→B5b: какие свидетельства и артефакты
  меняют состояние и как меняется решение.

## Запуск

Из корня репозитория, нужен только PyYAML:

```bash
python3 paper/integrity-architecture/calc.py                   # пересчёт и сводка
python3 paper/integrity-architecture/calc.py --check           # сверка с results.json, код возврата 0 или 1
python3 paper/integrity-architecture/calc.py --json out.json   # сохранить результат
```

С клоном scii-gate вместо копии: `--gate <путь к scii-gate на теге v0.1.5>`.

Ожидаемый результат: пересчёт побитово совпадает с `results.json`. Решения всех 16 сценариев и
272 состояния свидетельств совпали с программой испытаний стенда (`run_checks`).

Тест [`tests/test_paper_integrity_architecture.py`](../../tests/test_paper_integrity_architecture.py)
проверяет копии входных файлов, побитовое совпадение пересчёта и числа таблицы 3.

## Что сюда не входит

- Самопроверка конвейера [rbpo-pipeline](https://github.com/alexqzm/rbpo-pipeline) 5 ноября 2026 г.
  (31 артефакт из 98, полнота для процессов 5.4, 5.12, 5.13, 5.14, 5.18 и 5.20) взята из отчёта
  прогона GitHub Actions 42007116806 этого конвейера.
- Проверка квитанции допуска на устройстве выполнена в [scii-verify](https://github.com/alexqzm/scii-verify)
  и в эксперименте не участвует.

## Ограничения

Сопоставление μ задано автором модели на уровне связи, а не эквивалентности. Проверки (6) построены
по структуре стандарта, сам стандарт таких правил решения не устанавливает. Разметку сценариев автор
задал до прогона, независимой разметки нет.
